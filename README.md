# SONshine-Wiki
Arbeitspaket 4 - Überprüfen & Testen

Ziel: Schauen, ob alles richtig funktioniert und gut aussieht.

 4.1: Alle Links anklicken (Prüfen, ob jede Seite und jeder Button funktioniert).  

 4.2: In verschiedenen Browsern öffnen (Ausprobieren in Chrome, Firefox und Edge).  

 4.3: Auf verschiedenen Geräten testen (Schauen, wie es auf dem Handy und am PC aussieht).  

 4.4: Rechtschreibung kontrollieren (Alle Texte noch einmal durchlesen und Tippfehler korrigieren). 

 4.5: Code auf Fehler prüfen (Schauen, ob irgendwo im HTML/CSS Klammern oder Tags fehlen).  

 4.6: Ladezeiten und Bildgrößen prüfen (Große Fotos verkleinern, damit die Seite schnell lädt).  

 4.7: Mitschüler testen lassen (Einem anderen Team die Seite zeigen und schauen, ob sie sich zurechtfinden).
