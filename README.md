# SONshine-Wiki
Arbeitspaket 5 - Präsentation 

Ziel: Die fertige Schulwebsite der Klasse und dem Lehrer vorstellen.

 5.1: Aufgaben für die Präsentation verteilen (Wer stellt welchen Teil der Website vor?).  

 5.2: Präsentationsfolien erstellen (Kurz aufschreiben: Idee, Ablauf, Ergebnis).  

 5.3: Live-Durchklicken vorbereiten (Zeigen, wie die Website funktioniert und wie die Seiten aussehen).  

 5.4: Ein Stück Code erklären (Ein kurzes Beispiel aus HTML/CSS raussuchen und erklären).  

 5.5: Probleme und Lösungen aufschreiben (Was beim Programmieren schwer war und wie wir es gelöst haben).  

 5.6: Präsentation einmal im Team durchsprechen (Stoppuhr mitlaufen lassen).  

 5.7: Projektordner abgeben (Den kompletten Ordner beim Informatiklehrer einreichen).
