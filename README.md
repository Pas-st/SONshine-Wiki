# SONshine-Wiki
Arbeitspaket 3 - Programmieren

Ziel: Die Website im Informatikunterricht Schritt für Schritt programmieren.

 3.1: Ordnerstruktur auf dem PC anlegen (⁠index.html⁠, Unterseiten, Ordner für CSS und Bilder).  

 3.2: Grundgerüst der Startseite schreiben (HTML-Basiscode anlegen).  
 
3.3: Menüleiste bauen (Logo einfügen und Links zu allen Unterseiten im Header platzieren).  

 3.4: Startseite mit Text aus Arbeitspaket 1 befüllen (Willkommenstext, Schulprofil etc).  

 3.5: Seite für LernSax & Schulmanager programmieren (Links und Anleitungen einfügen).  

 3.6: Seite für Räume und Ausstattung bauen (Bilder und Texte zu PC-Kabinetten und Werkstätten einsetzen).  
 
3.7: CSS-Datei erstellen und verknüpfen (Farben, Abstände und Schriftgrößen einstellen).  

 3.8: Ansicht anpassen (Verhindern, dass alles verrutscht beim öffnen der Seite).  

 3.9: Fußzeile programmieren (Schuladresse, Impressum und Abgabe-Name eintragen).
